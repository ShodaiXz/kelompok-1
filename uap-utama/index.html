Materi yang Pernah Dipelajari

Microsoft Word

Microsoft Word adalah perangkat lunak pengolah kata yang memudahkan pembuatan dokumen dan laporan. Materi yang dipelajari meliputi:

  • Drop Cap
  • Pembuatan dan struktur makalah
  • Mail Merge
  • Shortcut Microsoft Word
  • Fitur Comment dan Track Changes
  • Pembuatan daftar isi
  • Daftar gambar dan daftar tabel

Microsoft Excel

Microsoft Excel adalah perangkat lunak spreadsheet yang digunakan untuk mengolah angka dan menganalisis data. Materi pembelajaran yang dipelajari meliputi:

  • Fungsi aritmatika (penjumlahan, pengurangan, dll.)
  • Fungsi COUNT dan pengolahan data
  • Pembuatan dan penggunaan diagram
  • Pivot Table untuk analisis data
  • Visualisasi data dalam bentuk grafik

Microsoft PowerPoint

Microsoft PowerPoint digunakan untuk membuat presentasi berbentuk slide yang menampilkan poin-poin utama secara ringkas dan visual. Materi pembelajaran meliputi:

  • Pembuatan slide presentasi yang terstruktur
  • Penggunaan teks singkat dan poin-poin utama
  • Pemanfaatan visual yang relevan (gambar dan ikon)
  • Penggunaan SmartArt untuk penyajian informasi
  • Pemilihan template dan desain slide
  • Pengaturan font agar presentasi mudah dibaca

Database

Basis data adalah kumpulan tabel yang digunakan untuk menyimpan data secara terstruktur agar rapi, aman, dan mudah dicari. Materi pembelajaran meliputi:

  • Konsep dasar basis data dan tabel
  • Pengelolaan data menggunakan DBMS
  • Penggunaan Microsoft Access sebagai DBMS
  • Penggunaan MySQL untuk pengolahan database
  • Pembuatan tabel dan pengelolaan database melalui Command Prompt (CMD)
